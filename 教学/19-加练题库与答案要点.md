# 《Web 网页技术》习题集与答案要点

> **使用说明**
> - **第 1–7 章题目**（并入原样）：可作为课后作业、随堂测、期末复习题。
> - **第 8 章 前端安全**（本课程新增，依据 [[22-前端安全专章（OWASP × ATT&CK）]]）：只考**判断力**——读代码判漏洞、选防线、写验收标准；**题目与答案均不含任何可直接使用的攻击载荷或绕过步骤**。
> - **答案要点**：只给**判分要点与关键词**，不给可直接抄写的完整答案；编程题给**思路与关键调用**，不给成品代码。
> - **评分口径**：简答题按"要点命中数"给分；编程题按"是否满足验收点"给分，代码风格不单独扣分（另由实验评分覆盖）。
> - **本习题集的一条原则**：不考背术语定义，考**能不能用来判断和排查**。凡是有争议的解释，题后附"阅卷提示"。
> - **工具操作（Windows / Linux）**：答案要点里说「用开发者工具看」「看 Network / Event Listeners 面板」的，按这几步做——按 **F12**（或 `Ctrl+Shift+I`）打开开发者工具 → 点 **Network** → 按 **F5** 刷新后读请求与响应头（在头与响应里搜字符串 `Ctrl+F`、录制 `Ctrl+E`、重放选中请求 `R`、绕缓存对比 `Ctrl+Shift+R`）→ 看「写的 HTML」与「解析后的 DOM」的差别用 **Elements**（`Ctrl+Shift+C` 可直接点选元素）→ 数监听器用 **Elements → Event Listeners** → 看报错原文用 **Console**（`Ctrl+Shift+J`）。凡涉及请求、缓存、存储的题，一律用本地服务器 `http://127.0.0.1:<端口>/` 访问，**不得用 `file://`**；快捷键与资料速查见 [[21-操作与资料速查（全可点）]]。

| 10 | √ | SRI 用哈希校验；不匹配则**拒绝执行**。这正是"分发环节被篡改"（如 CDN 被攻陷）的第一道拦截 |

| 17 | 要点 | ① **CWE-79 XSS**（DOM 型／Type 0；OWASP 归类在 A05:2025 Injection）。② 框架插值走"文本节点"赋值，不解析 HTML；`innerHTML` 会按 HTML 解析，于是数据被当代码。③ 改法一：`textContent`（放弃高亮）；改法二：保留"高亮"需求时——**先转义成文本，再用受控的方式加标记**（或用经过考验的净化器），并配 CSP／Trusted Types。**阅卷提示**：只答"过滤 `<script>`"不得分（过滤字面量不是防御） |
| 18 | 要点 | ① 缺的是**来源校验**（`event.origin` 用白名单比对）。② 因为 `postMessage` 的接收方是"谁都能给它发消息"的；任何站点只要拿到本页的窗口引用（嵌入或打开），就能投递数据 → 数据被当 HTML 插入即形成注入。③ 改法：校验 `event.origin` 是否在白名单内、校验 `event.source`、**并且不把 `event.data` 送进 `innerHTML`**（送进也要净化）；发送侧指定具体 `targetOrigin` 而非 `*` |
