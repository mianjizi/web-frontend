## 一、开发者工具：怎么打开、怎么用

### 1.1 快捷键（Windows / Linux）

| 要做什么 | Windows / Linux | Mac |
|---|---|---|
| 打开开发者工具（回到上次用的面板） | **F12** 或 `Ctrl+Shift+I` | `Command+Option+I` |
| 打开控制台 Console | `Ctrl+Shift+J` | `Command+Option+J` |
| 打开 Elements 并直接点选元素 | `Ctrl+Shift+C` | `Command+Shift+C` |
| 切换设备模式（手机视图） | `Ctrl+Shift+M` | `Command+Shift+M` |
| 打开命令菜单（能搜所有功能） | `Ctrl+Shift+P` | `Command+Shift+P` |
| 普通重载 | `F5` 或 `Ctrl+R` | `Command+R` |
| **硬性重载**（绕过缓存） | `Ctrl+F5` 或 `Ctrl+Shift+R` | `Command+Shift+R` |
| 在所有资源里搜字符串 | `Ctrl+Shift+F` | `Command+Option+F` |
| 清空控制台 | `Ctrl+L` | `Command+K` |
| 在 Elements 里把选中元素改成 HTML 编辑 | 选中后按 **F2** | `Fn+F2` |
| 暂停 / 继续脚本执行 | `F8` | `F8` |
| 单步跳过 / 单步进入 / 跳出函数 | `F10` / `F11` / `Shift+F11` | 同左（Ctrl 换 Command） |

**Network（网络）面板专用**：

| 要做什么 | Windows / Linux |
|---|---|
| 开始 / 停止记录 | `Ctrl+E` |
| 记录一次重载（不点它就可能抓不到首屏请求） | `Ctrl+R` |
| 重放选中的请求 | `R` |
| 在头与响应里搜字符串 | `Ctrl+F` |
| 关闭右侧详情栏 | `Esc` |

**打开 Network 面板的标准五步**（照做即可，来源见文末）：

1. 按 **F12**（或 `Ctrl+Shift+J`）打开开发者工具；
2. 点顶部标签 **Network**（中文界面叫「网络」）；
3. 按 **F5** 刷新页面——**必须在打开面板之后再刷新**，否则抓不到首屏请求；
4. 点左侧列表里的任意一条请求；
5. 右侧看 **Headers**（请求/响应头）、**Preview** / **Response**（内容）、**Timing**（各阶段耗时）。


> 快捷键取自 Chrome 官方文档「[DevTools 键盘快捷键](https://developer.chrome.com/docs/devtools/shortcuts)」，不是转述。**笔记本键盘若 F 键被系统功能占用，需按 `Fn+F12`。**

### 1.2 本课程最常用的四个面板

| 面板 | 打开方式 | 用它做什么 |
|---|---|---|
| **Elements** | `F12` → 点 **Elements**；或 `Ctrl+Shift+C` 直接点选元素 | 看真实的 DOM（浏览器解析后的结构，不含你的语法错误）、看某个样式为什么没生效、改 HTML 试效果 |
| **Console** | `Ctrl+Shift+J` | 看报错原文（**报错要照抄原文，不要只写"报错了"**）、用 `console.table` 看数组、临时试一行代码 |
| **Network** | `F12` → 点 **Network** → **然后按 F5 刷新** | 看请求有没有发出、状态码、请求头/响应头、是否命中缓存、耗时分布 |
| **Application** | `F12` → 点 **Application** | 看 `localStorage` / `sessionStorage` / Cookie 到底存了什么；手动清缓存 |

### 1.3 三个最常用的操作

- **绕过缓存拿最新文件**：硬性重载 `Ctrl+Shift+R`；或在 Network 面板勾 **Disable cache** 后保持面板开着。
- **看首屏请求**：先开 Network 面板，**再**刷新（`F5`），否则列表是空的。
- **只抓某一类请求**：Network 面板的筛选栏点 **Fetch/XHR**（接口请求）或 **CSS/JS**（静态资源）。

## 三、本地开发的常用命令（可直接复制）

```bash
# 起一个静态服务器（三者任选其一，端口以终端输出为准）
python -m http.server 8000          # 前提：本机装了 Python
npx serve .                          # 前提：装了 Node
npx vite preview                     # 前提：本项目由 Vite 构建过

# Vite 项目三条命令
npm run dev        # 开发服务器，默认 http://localhost:5173/
npm run build      # 产出到 dist/
npm run preview    # 用本地服务预览 dist/ 的产物（不要用 file:// 打开 dist/index.html）
```

> **硬规矩**：凡涉及请求（`fetch`）、CORS、缓存、`localStorage` 的实验与考核，**不得用 `file://` 直接打开页面**——`file://` 下请求会被拦、跨域与缓存行为失真，会出现"按题目做却全卡死"的假故障。用上面的本地服务器访问 `http://127.0.0.1:<端口>/...`。
