## 怎么用

**自学**：从 [`自学版/00-自学指南.md`](自学版/00-自学指南.md) 开始。每篇结构固定：心智模型 → 精讲 → 关键概念讲透 → 动手 → 自测 → 自我检查 → 依据说明。客观题给答案与解析，动手题只给验收标准、不给成品实现。

**开课**：从 [`教学/00-课程大纲.md`](教学/00-课程大纲.md) 开始。96 学时（讲授 64 + 实验上机 32），按「模块 + 学时建议」组织，可按模块裁剪为 32 / 48 / 64 / 96 学时四种拼法。

**安全专题**：先看 [`教学/23-安全审视报告（初学 + 网安视角）.md`](教学/23-安全审视报告（初学%20+%20网安视角）.md)（19 条问题清单与处置对账），再看 [`教学/22-前端安全专章（OWASP × ATT&CK）.md`](教学/22-前端安全专章（OWASP%20×%20ATT%26CK）.md)（按 OWASP Top 10:2025 与 MITRE ATT&CK 组织，写明框架映射与覆盖边界）。

## 几点说明（重要）

- **不是可以直接粘贴交差的成品**：练习只给「任务 + 验收标准」，答案要点只给判分要点与关键词，示例代码只标示语法形态。
- **出处逐条标注**：每篇末尾分「有官方依据」与「属本人编排判断（官方材料无此规定）」两类；事实性内容引规范、官方文档或原始披露，外链均逐条实测可达。
- **版本口径**：所有版本号来自 npm registry 与本机实测，不是网络文章转述；口径表见索引页。
- **安全内容红线**：只讲机制、防御与检测，**不含任何可直接使用的攻击载荷或绕过步骤**；实践一律指向合法靶场（OWASP Juice Shop 等），并把未授权测试的法律边界单独立节。
- **图的渲染**：图表用 mermaid 代码块（Obsidian 原生渲染）与手写 SVG（`figs/`）；本仓的图都按 Obsidian 的 `securityLevel: strict` + mermaid 11.13.0 校验过语法与渲染宽度。
